# طبيب السياكل — متجر الدراجات الهوائية

مشروع Android أولي باسم **طبيب السياكل** لمتجر **الدراجات الهوائية فقط**، بواجهتين أساسيتين:
1. **قطع غيار الدراجات**: تصنيفات للدراجات الكبيرة والصغيرة، ثم قائمة قطع الغيار.
2. **لوازم الدراجات وزينتها**: خوذات، أضواء، أجراس، سلال، حوامل هاتف، وملحقات أخرى.

## سلوك المنتجات
- الأسعار تبدأ فارغة حتى يضيفها صاحب المحل.
- لكل منتج زر «اطلب الآن» يفتح واتساب برسالة جاهزة باسم المنتج.
- يجب ضبط رقم واتساب للمحل في `app/src/main/java/com/example/bikeshop/ShopConfig.kt` قبل الاستخدام.
- الصور الحالية رسومات توضيحية محلية SVG قابلة للاستبدال بصور منتجات المحل.

## ملاحظات قبل النشر
هذا إصدار تأسيسي وليس إصدارًا جاهزًا للنشر التجاري. لا توجد حتى الآن قاعدة بيانات أو تسجيل دخول إداري آمن متعدد الأجهزة. يجب تنفيذ مصادقة مالك حقيقية وتخزين مركزي قبل اعتبار تعديل الصور والأسعار محصورًا بالمالك على نحو آمن. لا تُدخل بيانات شخصية حقيقية قبل إكمال ذلك.

## البناء
يفتح المشروع في Android Studio. يتطلب Android SDK وJDK 17. يوجد GitHub Actions workflow لتجربة بناء Debug APK تلقائيًا.
